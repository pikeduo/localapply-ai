当前为本地文件管理模式：配置和资料保存在此浏览器的独立 IndexedDB，与插件数据互不自动同步。可通过 JSON 备份交换资料（备份不含 API 配置/Key）。获取模型、测试连接和 AI 解析需要服务端允许文件页的跨域请求；网页自动填充需从插件入口使用。

模型与密钥 可选

不配置 AI 也能手动管理资料并使用本地规则填写。AI 可用于简历文件识别、未知字段建议和开放题草稿，每次发送均由你主动操作。

支持 DeepSeek、Qwen、Kimi、智谱、OpenAI、硅基流动、OpenRouter 和 Ollama。输入 IP 或接口地址后按回车或移开焦点，自动保存为自定义服务商。完整 http(s) URL 保留原路径；仅省略协议的 IP/域名默认补 /v1。

口令保护（可选，不影响直接填写 API Key）

安全口令是你自行设置的本地保护密码，不是服务商的 API Key。可不设置；已启用时，使用原口令可取消保护。默认本机保存模式不提供独立口令保护。资料备份均不包含 Key。

文件页受浏览器 CORS 限制。可从浏览器扩展管理页打开本插件的设置，在该入口重新填写接口和 Key（与文件页独立保存），并允许访问该接口站点。

继续使用 file:// 时，请由 sub2api 管理员在现有配置的 cors.allowed_origins 中加入字符串 "null"，保留原有来源并重启服务；前置反代也须放行 OPTIONS、Authorization 和 Content-Type。

401/403 请检查 Key、分组及访问权限；404/405 请核对接口前缀或版本。模型列表接口未开放时可手填管理员提供的模型 ID，但手填无法解决网络或跨域问题。

502/503/504 表示接口链路或服务端故障。请按页面显示的请求编号查询反代与 sub2api 日志，并对照其他客户端实际使用的 Base URL、请求路径和协议；同一 Key 能在 Codex 客户端使用，不代表模型列表及聊天接口都已可用。

自定义服务商可选择 Chat Completions 或 Responses，请与已验证可用客户端的协议一致。模型列表仍请求当前地址下的 /models；推理协议切换不能保证修复模型列表的 502。Anthropic /messages 尚不支持。

主模型和视觉模型展开时均显示完整已获取列表，不按已选值过滤；本标签页刷新可复用近期列表。获取失败时可手动填写 ID。列表不代表识别能力，仍需实测。

数据与隐私

公共字段导出只含元数据；个人自定义字段默认不公开，不包含个人值、档案、记录或 Key。本阶段不连接 GitHub。

备份包含全部档案和字段值，不含 API Key。换电脑或重装浏览器前建议先导出。

资料与 API 设置分别存在本机 chrome.storage.local，原简历文件不保存。AI 调用只在你主动触发时将必要内容发送到配置的服务商。 插件永不自动点击任何「提交/投递」类按钮，最后一步永远由你本人操作。
