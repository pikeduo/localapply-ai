网申自动填写助手 · 设置

① AI 服务（可选，不用 AI 可整节跳过）

不配置 AI 完全不影响使用：直接在侧边栏「字段库」手动录入，核心的一键填充零配置可用。AI 只用来加速两件事：简历 PDF 自动提取、开放题起草。

支持 DeepSeek、Qwen、Kimi、智谱、OpenAI、硅基流动、OpenRouter 和 Ollama。输入 IP 或接口地址后按回车或移开焦点，自动保存为自定义服务商；仅根地址自动补 /v1。

填写接口和所需 Key 后，先获取模型列表，再选择主模型。

模型列表来自当前服务商；获取失败或接口未开放时可手动填写。列表本身不一定说明聊天或图片能力，视觉模型请按服务商说明选择。

主模型处理普通 PDF（pdf.js 本地抽出文字，纯文本模型即可）和开放题起草；视觉模型只在扫描件 PDF 时用到，留空 = 用主模型。纯文本模型读不了扫描件是物理限制（页面本质是照片），不是插件限制。

② 填充设置

label 与同义词表匹配得分 ≥ 阈值才自动填（调低更激进，调高更保守）

③ 简历 PDF 导入

流程：PDF → pdf.js 抽文本 → 不足 200 字或乱码率超 30% 自动改走 GLM 视觉模式（逐页）→ 提取结果先进入上方校对区，人工确认后才写入档案。禁止跳过校对直接入库。

④ 模板管理

全字段模板（互联网 + 央国企合并，51 字段）：新建档案（侧边栏顶部「＋」）默认带全部字段，有值就填、没值自动跳过；字段可在档案里随意增删改。

⑤ 数据与隐私

公共字段导出只含元数据；个人自定义字段默认不公开，不包含个人值、档案、记录或 Key。本阶段不连接 GitHub。

备份包含全部档案和字段值，不含 API Key。换电脑或重装浏览器前建议先导出。

资料与 API 设置分别存在本机 chrome.storage.local，原简历文件不保存。AI 调用只在你主动触发时将必要内容发送到配置的服务商。 插件永不自动点击任何「提交/投递」类按钮，最后一步永远由你本人操作。

⑥ 重复经历（本地数据管理）

教育、实习、工作、项目分别保存多条经历。此处数据已纳入备份；当前填表引擎仍使用侧边栏平面字段，重复区块自动匹配将在后续阶段接入。
