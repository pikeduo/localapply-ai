# 阶段二：简历导入与本地密钥加密

执行日期：2026-10-24。本阶段由用户授权执行，不推进网页字段学习及新的 ATS 适配。

## 已实现

- 简历中心支持新建档案、编辑基本资料和动态字段、管理多段教育/实习/工作/项目。
- PDF.js 从 3.11.174 升级为 6.4.299；Mammoth 1.13.0 与 fflate 0.8.3 本地打包。兼容资源及完整许可证随扩展分发；根 MIT/作者版权未修改。
- 本地读取预览不联网；用户点击发送后才调用所选模型。校对区显示来源、是否通过文本核实及目标档案当前值，无依据项和扫描项默认不选。
- 编辑过的提取值标为人工校对；确认时仅提交勾选项，默认补空白。文件指纹+档案+经历类别+序号用于重复导入去重。换文件、取消、解析失败均不提交资料。
- 私有备份包含已确认来源；公共字段包不包含个人来源、值或文件指纹。API 配置/Key/保险库不进入备份。

## 数据变化

规范库为 Schema v3。新增可选 `fieldValues.evidence`：

```json
{"kind":"pdf","excerpt":"连续原文片段","page":1,"verified":true,"fingerprint":"文件 SHA-256"}
```

kind 为 pdf/docx/vision/manual；excerpt 最多 500 字；DOCX 的 page 表示文本块。verified 只表示本地文本比对通过，不等于对履历真实性的认证；最终仍由用户确认。手动修改字段会清除此前证据。重复经历通过 entryId 保存，不再摊平成自定义长文本。

v2 数据、备份、恢复点经完整校验升级到 v3；版本升级仅一次增加 revision。失败保留旧库，未知版本拒绝写入。原版档案备份仍可导入。

`localapply.keyVault` 保存 AES-256-GCM 封套，PBKDF2-SHA256 600,000 次，16 字节随机 salt、每次独立 12 字节 IV。当前版本把各服务商 Key 置于同一认证加密载荷，AAD 绑定保险库协议版本，服务商 ID 在密文内关联其 Key。口令及不可导出 CryptoKey 不落盘。重启/后台回收即锁定，本地资料操作不受影响。

旧 Key 迁移顺序：写入密文 → 读回并认证解密 → 清理独立 API 配置和旧源中的明文 Key。其他旧资料保留；中断通过 pending 标记在正确口令解锁后重试。错误口令不写存储；个人资料库本身不加密，逻辑删除不等于物理磁盘擦除。

## 资源与权限

- 文件最多 10 MiB；PDF 最多 30 页；文本最多 100,000 字；扫描图片合计最多 16 MiB。
- DOCX 先验证 ZIP 目录并逐块统计实际解压量（40 MiB/2,000 项），仅重建已验证 XML 给 Mammoth；不转换/插入文档 HTML，不读取嵌入媒体或外部图片。
- PDF task、canvas、原字节、页面图及全文仅临时存在内存。取消会中止网络并使迟到响应失效；关闭页面清理草稿。
- MV3 仅增加本地 WASM 编译许可，以支持 PDF 图像解码；不允许 JavaScript eval。QuickJS 执行器不随包分发。
- file:// 使用独立 IndexedDB 和口令会话，不与扩展共享数据或 Key；调用模型继续遵守 CORS。
