# 阶段二：简历导入与本地密钥加密

执行日期：2026-10-24。本阶段由用户授权执行，不推进网页字段学习及新的 ATS 适配。

本记录已按用户后续纠正更新：简历由大模型/视觉模型识别，撤掉本地文字抽取和字数判扫描件的路径。代码仅安全检查、转图、校验模型 JSON 和处理人工确认。

## 已实现

- 简历中心支持新建档案、编辑基本资料和动态字段、管理多段教育/实习/工作/项目。
- PDF.js 6.4.299 只转图；docx-preview 0.4.1/html2canvas 1.4.1 渲染 DOCX 图文，fflate 0.8.3 做有界容器检查。历史 Mammoth 资源与许可保留，运行页面不再加载。
- 分别实测图片、图片型 PDF、纯图片 DOCX 是否识别出随机数字，不相信型号、自述或 HTTP 200。结果按端点/型号/Key 隔离，仅缓存 30 分钟，不进入数据库或备份。接口拒绝与网络/鉴权失败、识别未通过分别展示。
- 本地页面图片预览不联网；用户明确发送后，由通过实测的模型优先识别原文件，否则使用完整页面图片。无已验证路径时禁止发送，不退回纯文本解析。全部页面在一次模型请求中提供，便于跨页理解。
- 所有新候选默认不勾选，模型引用不冒充本地核对结果。逐项人工确认后保存；原文件、图片和探针只在内存处理。
- 编辑过的提取值标为人工校对；确认时仅提交勾选项，默认补空白。文件指纹+档案+经历类别+序号用于重复导入去重。换文件、取消、解析失败均不提交资料。
- 私有备份包含已确认来源；公共字段包不包含个人来源、值或文件指纹。API 配置/Key/保险库不进入备份。

## 数据变化

规范库为 Schema v3。新增可选 `fieldValues.evidence`：

```json
{"kind":"pdf","excerpt":"连续原文片段","page":1,"verified":true,"fingerprint":"文件 SHA-256"}
```

kind 为 pdf/docx/vision/manual；excerpt 最多 500 字，来自模型引用。新导入的 verified 一律 false；保留历史已比对字段的兼容读取。page 为模型标注且在预览范围内的页/图序号，DOCX 可能不同于 Word 分页。人工改值标 manual，之后再次手动修改会清除旧证据。重复经历通过 entryId 保存。

v2 数据、备份、恢复点经完整校验升级到 v3；版本升级仅一次增加 revision。失败保留旧库，未知版本拒绝写入。原版档案备份仍可导入。

`localapply.keyVault` 保存 AES-256-GCM 封套，PBKDF2-SHA256 600,000 次，16 字节随机 salt、每次独立 12 字节 IV。当前版本把各服务商 Key 置于同一认证加密载荷，AAD 绑定保险库协议版本，服务商 ID 在密文内关联其 Key。口令及不可导出 CryptoKey 不落盘。重启/后台回收即锁定，本地资料操作不受影响。

旧 Key 迁移顺序：写入密文 → 读回并认证解密 → 清理独立 API 配置和旧源中的明文 Key。其他旧资料保留；中断通过 pending 标记在正确口令解锁后重试。错误口令不写存储；个人资料库本身不加密，逻辑删除不等于物理磁盘擦除。

## 资源与权限

- 文件最多 10 MiB、30 页/图，页面图片合计最多 16 MiB。
- DOCX 先校验 ZIP 目录并逐块统计解压量（40 MiB/2,000 项），保留内嵌图片、字体和版式；删除外部关系。临时 iframe 禁脚本/外网，关闭 altChunk，转图后销毁。图片无法显示会阻止发送并提示转 PDF，不静默丢图。长流文档切图覆盖完整高度。
- PDF task、canvas、原字节、页面图及全文仅临时存在内存。取消会中止网络并使迟到响应失效；关闭页面清理草稿。
- MV3 仅增加本地 WASM 编译许可，以支持 PDF 图像解码；不允许 JavaScript eval。QuickJS 执行器不随包分发。
- file:// 使用独立 IndexedDB 和口令会话，不与扩展共享数据或 Key；调用模型继续遵守 CORS。

原文件协议参考 [OpenAI File inputs](https://developers.openai.com/api/docs/guides/file-inputs)、[OpenRouter PDF inputs](https://openrouter.ai/docs/guides/overview/multimodal/pdfs)。当前检测针对兼容的 Chat Completions 内容块接口，不代表服务商全部专用文件 API；OpenRouter PDF 指定 native，避免自动退到独立 OCR 服务。

没有使用真实简历或真实服务商 Key；模型提取质量、真实招聘站点及复杂 PDF 字体/扫描编码尚未系统实测。文件页可能限制本地字体/CMap/WASM 读取，复杂 PDF 优先用插件入口；跨页经历合并和重复区块网页匹配仍属后续阶段。
