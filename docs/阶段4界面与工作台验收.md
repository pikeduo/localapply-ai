## 数据和关键接口

- Schema 仍为 v3，未修改现有数据格式、迁移、PDF/DOCX 识别或 API Key 密文格式。
- `LocalApplyProfileView.sections(database, profileId, includeEmpty)`：只读投影，按稳定经历分组，false/0 保留，敏感性独立判断；不按经历标题合并。
- `panel:layout`：仅持有有效卡片令牌的 iframe 可以发送有限数字位移或折叠开关。后台校验后转给当前顶层页；位置仅在本页内容脚本内存中，不进入备份。
- `panel:edit`：仅构造固定扩展内部 URL，校验档案 ID，分组参数只是定位键，禁止任意外部 URL。完整资料和 Key 不写进 URL。
- `attachField({fieldId, profileId})`：复用已存在定义，创建当前档案空绑定，幂等且不复制其他档案值。
- `editEntry({entryId, title})`：仅修改经历标题，稳定 ID、个人值和映射不变。
- 编辑/导入继续使用后台 revision；定义编辑开始时先读取最新快照，期间禁用表单，防止迟到回填覆盖中文输入。刷新/切换档案遇到未保存编辑先确认；其他页面已改同字段则拒绝覆盖。
