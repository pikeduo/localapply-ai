## 主要入口与结构

- `data/templates.js` 的 `FIELD_ALIASES` 保存四个自主同义词。新空库这两项定义使用字段版本2；既有库不自动迁移，运行时只查已存在定义，显式离线导入才更新元数据。
- `data/field-matching.js` 保留历史确认→本地定义/上下文的顺序。家庭成员不作为本人来源；同组/上下文多目标保留待选择。`data/mapping-compat.js` 的跨站索引仅驻留内存，完整比较标签/分组/经历/学历角色。
- `data/value-resolver.js` 提供 `equivalent(fieldId, actual, expected)` 和 `resolve(fieldId, value, options)`；返回 resolved/ambiguous/incompatible，值不写回个人资料。可信fieldId来自后台FillIntent；UI/AI不能定义执行策略。原生男→M的实际候选机制保留。
- `data/field-suggestions.js` 的 `catalogPreview()` 输出发送内容和覆盖说明；元数据相关性只决定候选预算，不参与自动填写置信判断。每个入选定义的来源引用组一起纳入字符预算。
- `content/controls/native.js`、`dropdown.js` 和 `verified-fill.js` 在准备、冲突保护及最终回读中使用同一来源语义。保留节点/候选身份、禁用检查、取消及120/240/500ms验证窗口；不是服务端保存证明。

词典审计当前为155字段、12分类、182索引键、599字面量入口、87正则标记；16处跨分类同名、3处规范化重复需要审查。这些计数包含多个入口及重复，不代表准确率，也不与第三方词典规模直接比较。

## 离线包契约

公共文件只允许：

```text
kind = localapply-rule-package
formatVersion = 1
packageId / release
compatibility { minSchema, maxSchema, fillContract }
source { name, reference }
fields [FieldDefinition]
sha256
```

字段定义继续只允许 fieldId/label/type/group/aliases/options/description/version。包不接受个人值、网页映射、脚本、XPath或选择器，最大1MiB/2,000定义。来源地址仅供显示，不发请求；摘要用于一致性校验，不是作者身份认证。

随附文件：`data/rule-packs/core-aliases-v1.json`，仅含自主整理的两项标准定义。`node tools/build-rule-package.cjs` 可确定性重建其JSON，测试核对摘要和实际文件一致；生成器不读取用户存储。

后台仍由 `data/local-store.js` 的排队命令处理：

| action | 行为 |
|---|---|
| previewPublicFields | 完整校验旧公共包并返回逐字段差异，不写库 |
| previewRulePackage | 校验格式/摘要/来源/兼容、包和字段版本、私有ID与语义冲突，返回revision及差异 |
| installRulePackage | confirmed和预览revision必需；复用原公共合并函数，先保存恢复点再等待持久化 |
| listRulePackages | 返回当前回执、版本和固定回滚阻断原因 |
| previewRuleRollback | 对照当前定义、个人值、映射、后续绑定及其他包依赖，只预览 |
| rollbackRulePackage | 再校验并确认，仅回退包贡献的公共元数据；不恢复整份个人库 |

个人库仍为Schema v5，旧features/semanticId及Key存储不变。本机回执单独保存在 `localapply.rulePackages`；最多10包、每包3个版本、总回执4MiB，达到上限拒绝而不自动删历史。回执没有个人值，但含用于删除保护的本机绑定ID，不进入公共导出、个人备份、AI或诊断日志。

普通v5备份包含安装后的公共定义及全部个人值，不含安装回执。恢复备份后重新导入包可核对当前定义；没有旧差异时只能登记回执，不能伪造旧元数据回滚能力。字段版本降低不能靠旧公共包重导实现。

新字段有0/false/文字、映射引用、安装后的其他绑定、后改定义或其他包依赖时阻止删除；更新已有字段时只回退元数据，若会违反现有个人值的Schema，校验失败并保留资料。Chrome批量多键写入不宣称事务性；失败不发布缓存或成功响应，恢复点保留，数据库与回执不一致时须人工检查。
