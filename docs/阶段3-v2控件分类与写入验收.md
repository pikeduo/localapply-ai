## 数据与接口

Schema 继续为 **v3**。已有 `fieldDefinitions`、`fieldValues`、`entries.entryId`、`mappingRules` 分表及备份机制保留。唯一新增持久属性是可选 `mappingRules.features.layout`，只允许：

- `date:year-month`
- `date:year-month-day`
- `phone:country-number`
- `address:province-city-district`

没有 layout 的旧规则指纹不变；普通备份导入/导出接受该白名单属性，并有实际往返测试。旧版代码不认识它时，先使用已有“导出兼容旧版 v3 的备份”入口，保留字段/值/经历而去除学习规则扩展，再回退代码并导入；不回退个人库 Schema，也不导出 Key。

主要接口：

- `LocalApplyFieldAdapters.groups/plan/fill/accepted/read`：本地组成复合字段、生成无副作用计划、写入与回读；DOM 引用不跨消息或进数据库。
- `learning:prepareAI({scanIds})`：只接受选中的未知项，不传实际值/HTML/简历。`recognize` 仍需预览令牌与发送确认；`cancelAI` 可中止执行中的请求。
- AI `action` 可选，兼容旧建议；仅允许 `map_existing_field/create_field_definition/skip_non_resume_control/needs_user_choice`。忽略和人工选择时引用必须全为空，不能夹带代码或点击命令。
- `learning:ignore`：本会话忽略/恢复，不改个人库。
- `learning:fill`：非空冲突返回 `needs_confirmation` 和仅对可信 UI 可见的差异。覆盖必须提供本次 `overwriteToken`，后台校验版本/新值/五分钟时效，页面再次比较原值。
- `FieldLearning.invalidate(tabId)`：清理导航或关闭页面的会话及模型任务。

## 手工复核

在项目目录手动运行 `python -m http.server 8000 --bind 127.0.0.1`，浏览器加载或重新加载扩展后访问 `http://127.0.0.1:8000/test-pages/phase3-composites.html`。使用合成档案填写姓名、电话、出生日期和毕业时间：

1. 点击卡片“自动填写此页面”：应离线填入已匹配项；区号、年月和网站操作不进入未知字段，协议/同步复选框保持原状。
2. 在网页姓名中填入不同内容后再次填写：应保留，展开该项覆盖差异并明确允许后才替换。
3. 手填“资格附加说明”，在卡片该项展开编辑器，读取网页内容→预览差异→确认保存→单项验证→记住映射。刷新网页再次填写，应使用本地记忆。
4. AI 测试可直接运行上述 Playwright 命令，使用本地 Mock；真实服务需用户自行配置，先勾选未知项再确认发送。
