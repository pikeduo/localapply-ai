日期：2026-10-25。起点提交 `3e86f02`；阶段三代码未暂存、未提交、未推送。仅开发本阶段，未进入阶段四。

## 实际实现

侧栏新增“智能填表”：授权当前招聘页 → 扫描元数据 → 本地匹配 → 可选 AI 预览/确认 → 人工选择来源或创建字段 → 差异预览/确认 → 单项或批量填写 → 延迟复读验证 → 可选记住已成功验证的映射。

- 扫描原生输入、多行、select、radio、单/多 checkbox、日期、月份、contenteditable、ARIA combobox；读取 label/ARIA/placeholder、选项及分组，不读取输入值。支持 open Shadow DOM 与动态新增区块。页面手填内容仅在用户主动点击“读取此网页字段”时读取。
- 扫描授权限当前文档及 URL；刷新、SPA 导航或切换档案后需重新确认。旧检测入口也改为主动授权，保留原匹配和填充能力。密码、验证码、同意条款、搜索控件不进入学习；登录/验证短表不采集字段。
- `FieldMatchingEngine` 优先使用同站、同档案、已确认并验证的记忆，然后标准字段/同义词及明确上下文；“第一学历”选择已保存的本科经历，“最高学历”按明确学历枚举选择。来源不唯一时不默认拿第一条。私有字段在无本站记忆时只提供待确认的通用建议。
- AI 复用现有客户端与加密 Key，只接收用户预览过的脱敏字段元数据、字段目录、来源引用及有值布尔标记。不会发送实际值、经历标题、完整简历、HTML、URL 查询或凭据。固定系统提示与网页文本分离。发送前后及客户端读取凭据时核对端点/协议/型号/Key 摘要。
- 模型 JSON 使用 `FieldSuggestionSchema`，严格检查额外属性、类型、引用、数量、文本及重复 ID。不接受模型提供个人 `value`、代码、HTML、选择器或执行步骤。置信度只显示；采用建议也不能直接写库/填写。
- 新字段可以复制已确认本地来源，或先保存空值再由用户补充。支持主动读取网页手填值。定义和值分开存储，预览可一次确认后原子保存，也支持先建空字段再单独确认值。新字段可明确归属一条重复经历，不覆盖其他经历。这里采用两个独立集合的原子提交，避免草案“两次写入”中第二步失败留下半成品。
- 填写复用原 setter、input/change/blur、文本与补全逻辑；外层对 select/radio/ARIA 选项采用精确匹配，避免包含匹配误选。复读真实 value/checked/selected/aria-selected/校验状态，观察跨延迟重渲染回退。页面不接受值时显示 failed，不能记忆。不会点击提交按钮或同意条款。
- 规则可查看、修改目标、禁用、删除、撤销本会话最近一次规则操作。改目标会清除验证状态，需要重新确认及填写验证。记忆前再次复读，网页值或本地值改变时拒绝保存。
- 无 Key/Key 锁定时本地扫描、手动选择、资料保存与规则填写继续可用。阶段二 PDF/DOCX、简历中心及密钥加密模块未重新开发。

## 数据与关键接口

继续使用 `schemaVersion: 3`、同一个 repository 和 `chrome.storage.local`，不引入运行时服务或新数据库。已有 v2/v3 迁移及备份逻辑保留。

`FieldDefinition` 仍只允许 `fieldId/label/type/group/aliases/options/description/version`。`ProfileFieldValue` 仍使用 `profileId/fieldId/entryId/value/source/updatedAt/evidence?`。学习来源为 manual、web-confirmed 或 local-confirmed；新定义默认私有，不加入 publicFieldIds。

扫描 DTO：`scanId/semanticId/label/name/type/placeholder/options/group/kind/degree/index`。运行节点 ID 只驻留内容脚本内存；语义 ID 不包含 DOM 随机 ID 或用户输入值。匹配命中后仍比较完整脱敏特征，不能仅信散列。

mappingRules 保留原字段，新增可选学习属性：

```json
{
  "mappingId": "mapping.<uuid>",
  "origin": "https://jobs.example.test",
  "path": "/",
  "label": "便捷联系号码",
  "fieldId": "custom.<uuid>",
  "profileId": "<profile-id>",
  "entryId": null,
  "semanticId": "semantic.<digest>",
  "features": {"label":"便捷联系号码","type":"text","group":"基本资料","kind":"","degree":"","index":0},
  "confirmed": true,
  "enabled": true,
  "lastVerifiedAt": "2026-10-25T00:00:00.000Z",
  "ruleVersion": 1
}
```

旧规则没有这些属性仍可读取/导入，但不会自动当作已验证记忆。特征使用白名单和脱敏校验；规则不得包含个人实际值、Key、HTML 或原文件。完整备份包含动态字段、值及规则，公共包继续只输出审核过的字段元数据。

| 可信后台接口 | 作用 |
| --- | --- |
| learning:scanPage / session / revoke | 明确授权扫描、同文档刷新、撤销授权 |
| learning:prepareAI / recognize | 返回接收方及 payload 预览，携带短期 token 和 confirmed 后才调用模型 |
| learning:select / readField | 选择本档案来源；主动读取单个网页字段值 |
| learning:previewValue / commitValue | 展示新旧差异，token + 数据 revision + confirmed 后入库 |
| learning:fill / remember | 明确确认填写；验证成功后再次确认记忆 |
| learning:rules / editRule / deleteRule / undoRule | 本地映射管理及本会话最近操作撤销 |
| learning:exportV3 | 下载去除学习扩展属性、保留资料的旧版兼容备份 |

新增 repository 命令 confirmField、deleteMapping、restoreMappings，沿用 expectedRevision 和全量校验后单次写库。内容脚本只能向后台报告无值的结构变化；不能读取这些接口、个人库或调用 AI。同一学习会话串行处理，防止刷新替换正在填写的行状态。

## 限制与下一阶段建议

- 本地合成页及真实 React/Vue 组件已验证；北森、Moka、飞书真实站点和真实模型仍须单独授权抽检。旧 Moka/国聘夹具回归通过不代表所有 ATS 版本兼容。
- closed Shadow DOM、跨域 iframe、未暴露 ARIA/候选项的自定义菜单、异步远程选项和复杂日期弹层需人工操作或后续适配。不会为了枚举候选而任意点击网页动作。
- 验证观察事件、校验状态及 500ms 延迟稳定回读，能抓住已测试的框架回退；无法证明任意框架内部/服务器最终接受，也无法保证更晚的回退不会发生。保存记忆前会再次验证；申请提交始终留给用户。
- 撤销为本会话最近一次规则操作；重启后的资料/规则回滚使用完整备份或兼容备份，不宣称无限历史版本。
- 元数据脱敏使用有界规则且调用前展示全部 payload，不能宣称能自动识别所有自然语言中的个人信息。字段值、原始 HTML 和简历内容从结构上不进入字段识别请求。
- 下一阶段建议在单独授权后整理阶段四 UI；真实 ATS 的深度适配按开发计划的后续阶段安排。本次在阶段三停止。
