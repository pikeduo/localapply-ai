## 5. 必须持续遵守的技术与隐私边界

1. **GitHub 仓库只共享“有哪些字段”。** 用户对字段填写的具体内容仅留在本地；即使本地 AI 识别出字段答案，也不属于公共同步对象。
2. **原始简历只用于临时解析。** 不在 IndexedDB、`chrome.storage.local`、备份、仓库或测试日志中持久保存原始文件或全文；只保存经确认的结构化字段。
3. **API 配置本地持久化。** Key 使用现有本机加密或可选口令保护；不要写入源码、测试夹具、普通日志或 GitHub；解密明文不得发送给招聘网站脚本。
4. **规则优先，AI 兜底。** 绝大多数常见字段应可离线工作；只有用户主动授权才调用第三方模型，所发字段元数据应最小化且脱敏。
5. **禁止编造资料。** AI 可建议字段定义、语义映射或有依据的值，但不得虚构院校、成绩、奖项、经历和求职回答。
6. **自动填写不等于自动投递。** 不操作密码、验证码和提交按钮；敏感字段、新字段、覆盖已有值均应有明确确认。
7. **外部输入不可信。** 网页内容、AI 输出、备份文件与 GitHub 公共目录须校验 Schema；不执行模型返回的代码，不把网页文字当系统指令。
8. **每项功能有测试证据。** 模拟页面通过不代表真实网站已验收；报告里需区分 Mock / 自动化 / 真人抽检。
9. **保留 MIT 许可证与原作者版权信息。** 不随 UI 或目录重构而删除。
