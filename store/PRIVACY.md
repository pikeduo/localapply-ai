# 网申自动填写助手 · 隐私政策

更新日期：2026-10-24

「网申自动填写助手」（以下简称"本插件"）是一款浏览器扩展，帮助用户在招聘网站申请表中填写自己预先保存的简历信息。我们非常重视你的隐私，本政策说明本插件处理哪些数据、数据存在哪里、以及数据的去向。

## 一、我们收集什么数据

本插件没有开发者资料服务器、埋点、统计 SDK 或广告，不向开发者收集或出售个人数据。用户主动触发的 AI 功能会向所选模型服务商发送必要内容，详见第二节。

你在使用中录入的以下数据**只保存在你本机浏览器**的 `chrome.storage.local` 存储中：

- 简历字段库与档案（如姓名、电话、教育经历等，由你本人录入或从 PDF 提取后校对确认）；
- 投递台账（你触发填充时的页面 URL 与时间）；
- 插件设置与 AI 起草的历史草稿；
- 多段教育、实习、工作和项目经历，以及本地网页字段映射；
- 所选服务商的 API 设置及 Key（独立存储，首次设置口令后加密，仅用于主动发起的 AI 功能）。

公共定义与个人值分别保存，内容脚本不能直接读取个人库、旧迁移源或 API 设置。升级保留旧个人资料；首次设置口令并验证密文后，清理 API 配置及旧源中的明文 Key。PDF/DOCX 原文件、图片和全文仅在内存处理。逐项确认后保存字段值、有限来源片段（每项最多 500 字）及去重用指纹；取消或解析失败不写入本次资料。

直接以 `file://` 打开设置页时，以上内容改存在该浏览器、该文件目录对应的独立 IndexedDB；文件页不能直接访问插件私有数据库，不自动同步个人资料或 Key。可通过 JSON 备份手动交换资料，API 配置不包含在默认备份中。文件页主动调用 API 使用浏览器标准跨域请求，服务端须允许对应来源和请求头。

附件材料清单只登记**文件名与备注文字**，本插件不读取、不存储任何文件本体。

## 二、数据的唯一对外去向：你选择的 AI 服务商

只有当你**主动点击**以下功能时，本插件才会发起对外网络请求：

1. **简历解析**：本地读取预览不联网。点击「发送内容给当前模型解析」后，将 PDF/DOCX 文本或扫描 PDF 图片发送至所选服务商，用于结构化提取；
2. **开放题起草**：将题目和你在档案中填写的素材段落发送至所选服务商，用于生成草稿。
3. **获取可用模型/测试连接**：获取模型时向当前接口请求模型 ID 列表，仅携带必要认证，不发送个人简历；测试连接只发送固定的测试问句。保存配置本身不会触发联网。

请求地址为你所配置服务商的 OpenAI 兼容接口，预设包括：智谱（open.bigmodel.cn）、DeepSeek（api.deepseek.com）、月之暗面（api.moonshot.cn）、阿里通义（dashscope.aliyuncs.com）、OpenAI（api.openai.com）、硅基流动（api.siliconflow.cn）、OpenRouter（openrouter.ai）；也可自行填写其他 OpenAI 兼容地址（首次使用时浏览器会弹出对该域名的授权询问）。你的 API Key 仅用于该请求的身份验证，按服务商分别保存在本机。除此之外，本插件不向任何第三方发送数据。所选服务商对请求数据的处理适用其自身隐私条款。

如果你不使用上述 AI 功能，本插件**零网络请求**（不联网也能完成全部手动填充功能）。

## 三、数据存储与删除

- 所有数据保存在本机浏览器配置目录中，不上传云端，插件没有服务器。
- 在扩展管理页移除本插件会删除插件本地数据；文件页独立 IndexedDB 不随卸载插件删除。清理浏览器中该文件来源的站点数据会删除文件模式数据，清理前请先备份。
- 你也可以随时在设置页「导出档案备份」自行备份，备份文件由你自行保管。
- 完整 JSON 备份含档案、字段、重复经历、已确认来源片段、映射和记录，不含 API 配置/Key、口令、保险库或原文件；导入可合并或覆盖，导入前保留一个个人库恢复点。
- “公共字段定义”导出只含已审核元数据，私有字段默认不公开，不含个人值、档案或记录。本版本不连接 GitHub，不自动上传任何字段包。

## 四、敏感信息保护

- 口令通过 PBKDF2-SHA256（600,000 次）派生密钥，API Key 使用 AES-256-GCM 加密，每次保存生成新 IV。口令不可找回，后台回收或文件页关闭后须重新解锁。个人简历库本身不加密；逻辑清理不保证磁盘历史副本物理擦除。

- 插件默认开启隐私遮挡：身份证号、手机号、家庭成员、期望薪资等敏感字段在侧边栏显示为 `••••`，点按才可见。
- 本插件**永远不会**自动点击任何「提交 / 发送 / 投递 / 确认」类按钮，所有表单的最终提交由你本人操作。
- 遇到验证码类控件，本插件自动跳过并提示，不做任何干预。

## 五、未成年人

本插件面向求职者群体，不面向 14 周岁以下儿童，不刻意收集儿童个人信息。
